## 🎮 About The Game

**Drive Mad** is a fun browser-based physics driving game where your goal is simple:

> 🚗 **Drive as far as possible without flipping your vehicle!**

Navigate through challenging terrain, jumps, bumps and gaps while keeping your vehicle balanced.

Every level becomes more challenging. Can you reach the finish line? 🏁

---

## ✨ Features

- 🚗 Physics-based driving
- 🏔️ Challenging terrain
- 🛣️ Ramps and obstacles
- 💨 Vehicle acceleration and braking
- 🔄 Mid-air vehicle rotation
- 🏁 Finish-line progression
- 🎮 Keyboard controls
- 📱 Browser-based gameplay
- ⚡ No installation required
- 🌐 Play directly from the browser

---

## 🕹️ Controls

| Key | Action |
|---|---|
| `W` / `↑` | Accelerate |
| `S` / `↓` | Brake / Reverse |
| `A` / `←` | Rotate Left |
| `D` / `→` | Rotate Right |
| `R` | Restart |

### 📱 Mobile

Use the on-screen controls when playing on touch devices.
