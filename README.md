## 🎮 ABOUT THE GAME

**Drive Mad** is a fast-paced browser racing game where your only job is to keep the car moving, balanced and alive.

Jump over ramps.  
Cross crazy terrain.  
Control the car in mid-air.  
And make it to the finish line without flipping. 🏁

<div align="center">

```text

      🚗━━━━━━━►

```

- 🚗 Physics-based driving

## 🕹️ CONTROLS

<div align="center">

| 🎮 KEY | ACTION |
|:---:|:---|
| `W` / `↑` | 🚀 Accelerate |
| `S` / `↓` | 🛑 Brake |
| `A` / `←` | ↩️ Rotate Left |
| `D` / `→` | ↪️ Rotate Right |
| `R` | 🔄 Restart |

## 🧠 PRO TIP

> **Don't always drive at maximum speed.**

Use acceleration carefully before ramps and use the air controls to keep the car balanced.

One bad flip can end the race. 💥
